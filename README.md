# maxmagia-site

Снимок сайта клуба с сервера 93.188.184.7 — для истории версий и отката.

- `maxmagia.ru/` — копия `/var/www/maxmagia.ru/` (лендинг, оферта, документы, страницы)
- `app.maxmagia.ru/` — копия `/var/www/app.maxmagia.ru/` (кабинет, практики, страницы входа)
- `nginx/` — копия `/etc/nginx/sites-available/`
- `SKIPPED.md` — что не попало (видео, звук, большие файлы)

Сохранить: `save-site "что изменилось"` (на сервере). Каждую ночь в 04:40 — автосохранение.
Кабинет (`index.html`, `letter.html`) по-прежнему обновляется через `maxmagia-app` → `update-app`;
здесь он только для истории.
